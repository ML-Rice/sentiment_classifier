## Review Sentiment Classifier 

Classifies movie or product reviews as positive or negative. 
Compare different pipelines: a rule-based lexicon baseline, Bag-Of-Words + Naive Bayes, TF-IDF + Logistic Regression. 
(Optional) Additionally classifies reviews as neutral. 

# Recommended Datasets: 
- IMDB Movie Reviews
- Amazon Product Reviews

# Evaluation:
All pipelines are scored on the same test set using:
- Accuracy, precision, recall, F1, and confusion matrices
- Misclassified examples
- The top features for each model
